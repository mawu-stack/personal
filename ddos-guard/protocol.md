# DDoS Guard experiment protocol

Fixed before training: use the Kaggle dhoogla/cicddos2019 mirror's named training/testing partitions; binary Benign versus non-Benign; eight explicitly listed flow features; median imputation fitted on training only; seed 42. Training-only conflicting feature patterns excluded and duplicates removed. Remove test patterns identical to retained training patterns, deduplicate test feature/target rows; report exclusions. Cap training at 120,000 stratified rows. Compare depth-5 class-balanced tree against a 100-tree depth-12 class-balanced Random Forest. No test-based tuning or model selection. Threshold is each classifier's default decision rule. Export tree for local browser inference; Random Forest remains offline evaluation only.

This is a bounded educational traditional-ML comparison, not a novel deep-learning contribution. The predefined partitions and cleaning of the third-party mirror need independent scrutiny; identity/time fields are unavailable. Feature-pattern disjointness is not proof of host/campaign disjointness. Portscan or other non-Benign labels may represent intrusion beyond DDoS; report all observed classes and avoid claiming pure DDoS detection for those records. Scores from this historical, cleaned collection are not deployment guarantees. No live monitoring or attack generation.
