## Original direction: “The defensive field”

An ink-black editorial portfolio with warm paper typography, blue-violet structure and a mint signal. A translucent, layered spherical field is drawn with SVG/CSS rather than a heavyweight imported 3D model. Visitors select a project orbit using ordinary accessible buttons. The field changes its accent, annotations and project description. This is an explicit illustrative navigation interaction, not live threat telemetry.

Projects alternate large visual exhibits, indexed rows and technical evidence, rather than repeating equal cards. K.E.A.N. is a recognizable focal object and a route into the existing assistant, not a fabricated chat transcript. The research preview uses the current locally generated DDoS metrics only, with limitations. Creator skills are taken from the existing coursework; no job history, awards, employers or certifications are added.
